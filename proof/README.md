# ui-glitch-hunter proof suite

This proof suite demonstrates UI Glitch Hunter against a scoped set of
source-backed examples. It is evidence for specific detector behavior, not a
claim of complete UI glitch coverage.

## Claims

| Claim | Source-backed example | Expected result |
|---|---|---|
| Layout-shift-like visual instability is detected when the browser reports movement. | `webdev-layout-shift-demo` | Browser `layout-shift` entries plus `large-delta` or `consecutive-instability`. |
| A documented no-flash theme implementation is not flagged for blank/dark flash. | `next-themes-no-flash` | No `blank-flash` or `dark-flash` events in light or dark color schemes. |

## Sources

Source contracts live in `proof/sources.json`.

- `webdev-layout-shift-demo` uses the web.dev debug-layout-shifts article and
  injects the documented DOM movement into that external article page. The
  article's linked Glitch demo now returns a hosting tombstone, so the browser
  Layout Instability API is the independent oracle and the injected movement is
  the controlled stimulus.
- `next-themes-no-flash` uses the next-themes project documentation and linked
  live example as a negative control.

## Commands

```bash
npm run proof
```

Runs local proof checks with external hosted proofs skipped by default.

```bash
npm run proof:external
```

Runs hosted-page proofs with `VISUAL_GLITCH_PROOF_EXTERNAL=1`, then writes proof
summaries.

Both commands use `scripts/run-proof.ts` through `jiti` instead of inline shell
environment syntax. The runner sets or clears `VISUAL_GLITCH_PROOF_EXTERNAL`,
runs the Playwright `proof` project, and writes summaries even when a proof test
fails.

## Artifacts

Proof runs write or attach:

- `proof/results/outcomes/*.json`
- `proof/results/summary.json`
- `proof/results/summary.md`
- visual glitch reports under `test-results/visual-glitches`
- Playwright attachments for source entries and external oracle data

Generated `proof/results/**` files are local/CI artifacts and are ignored by
git.

## Threshold profiles

The layout-shift proof should first record the default-threshold result. If the
external demo is not detected under defaults, the proof may use
`proof/layout-shift-sensitive`:

```ts
thresholds: {
  maxFrameDelta: 0.03,
  maxConsecutiveUnstableFrames: 2,
}
```

Reports and summaries must make the threshold profile explicit.

## Offline corpus workflow

Offline frame-file analysis is documented in `proof/offline-corpus.md`. It
covers `analyzeVisualFrameFiles`, manifest fields, GlitchBench research notes,
asset provenance, and the generated-frame proof strategy used in default proof
runs. The offline proof broadens source-backed evidence without vendoring
third-party corpus assets or claiming complete UI glitch coverage.

## CI behavior

Default PR CI should remain independent of third-party hosted pages. External
pages can move, fail, or change behavior without a project code change, so they
should not be required pull request gates.

```bash
npm run build
npm run typecheck
npm test
```

Nightly or manual CI may run:

```bash
npm run proof:external
```

Upload these artifact directories from manual/nightly proof runs:

- `proof/results`
- `test-results`

`proof/results` contains machine-readable and Markdown summaries. `test-results`
contains Playwright attachments plus any `report.html` and `report.json` visual
glitch reports generated by detector events.

## Reliability policy

External proof specs use explicit 45 second per-test timeouts. Retries are not
enabled by default because detector regressions and third-party page drift should
surface as actionable failures. Diagnostics attached to failures include the
source entry, navigation status where available, final URL, frame count, observed
detectors, oracle data, and proof outcome path.

## Limitations

- External hosted pages may change.
- This suite does not prove complete UI glitch coverage.
- Layout-shift proof uses visual correlation, not CLS scoring.
- Offline corpus coverage is a separate Phase 2 track and requires source,
  license, and asset-size review before ingestion.
